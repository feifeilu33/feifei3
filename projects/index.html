Featured Projects

Job Posting Data Analysis

This capstone project from the IBM Data Analyst Professional Certificate program applied techniques including API integration, web scraping with BeautifulSoup, data cleaning and normalization using Pandas, exploratory data analysis with Matplotlib and Seaborn, and dashboard development in IBM Cognos Analytics.

Email Fraud Detection (LSTM+GAN)

This project applied techniques including Python-based ETL for data preprocessing and label encoding, NLP pipeline engineering with tokenization and sequence embedding for LSTM model building, and adversarial training for GAN discriminator optimization.

Stock Price Prediction

This project employed NLP techniques to conduct sentiment analysis on Twitter data using the VADER tool, generating sentiment scores. These scores are then incorporated into LSTM models as features, alongside market indices such as the S&P 500 and Nasdaq, for time series forecasting of the stock's closing prices.

Harry Potter Chatbot

This is a conversational AI system using RAG. It includes modules for question classification, multi-source information retrieval, and response generation, using book texts, external APIs, and web searches to provide accurate and relevant answers.

Superstore Power BI Dashboard

This project utilized Power BI for a comprehensive visual analysis of supermarket sales data, focusing on sales trends, customer behavior, and product performance. The dashboard covered time-based, geographical, customer, and product analysis.
