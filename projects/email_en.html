Email Fraud Detection Using LSTM Model

This page demonstrates how to build a neural network model based on LSTM for classifying emails (spam or not spam).

Step 1: Import Necessary Libraries

Before getting started, we need to import various modules required for building the model.


import numpy as np
from tensorflow.keras.layers import Input, Embedding, LSTM, Dense
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.preprocessing.sequence import pad_sequences

Step 2: Define the Discriminator Function

We define a function named create_discriminator which takes maximum sequence length and vocabulary size as parameters, and returns an LSTM-based discriminator model.


def create_discriminator(max_sequence_length, vocab_size):
    discriminator_input = Input(shape=(max_sequence_length,))
    
    x = Embedding(input_dim=vocab_size, output_dim=embedding_dim)(discriminator_input)
    x = LSTM(units=64)(x)  # LSTM layer with 64 units
    
    spam_classifier_output = Dense(1, activation='sigmoid')(x)
    
    discriminator_model = Model(discriminator_input, spam_classifier_output)
    return discriminator_model

Step 3: Set Up Discriminator Components

The relevant parameters of the discriminator are set up, and the discriminator model is compiled using the Adam optimizer. The loss function is binary cross-entropy, and the evaluation metric is accuracy.


max_sequence_length = 100
vocab_size = 10000
embedding_dim = 100

discriminator = create_discriminator(max_sequence_length, vocab_size)

optimizer = Adam(learning_rate=0.0002, beta_1=0.5)
discriminator.compile(loss='binary_crossentropy', optimizer=optimizer, metrics=['accuracy'])

Step 4: Prepare Data

Convert the text and labels from the dataset into list format for subsequent processing.


email_text = data['text'].tolist()
labels = data['label_num'].tolist()

Step 5: Create and Fit the Tokenizer to Email Texts

Create a Tokenizer object and fit it to the email texts data using the fit_on_texts method.


tokenizer = Tokenizer(num_words=vocab_size)
tokenizer.fit_on_texts(email_text)

Step 6: Convert Texts to Numeric Sequences

Use the texts_to_sequences method to convert text data into numeric sequences where each word is replaced by its index in the vocabulary.


sequences = tokenizer.texts_to_sequences(email_text)

Step 7: Pad Sequences to Ensure Consistent Length

Use the pad_sequences method to either pad or truncate sequences so that they all have the same length max_sequence_length.


padded_sequences = pad_sequences(sequences, maxlen=max_sequence_length)

Step 8: Convert Labels to NumPy Array

Convert the list of labels into a NumPy array for further processing.


labels = np.array(labels)

Step 9: Shuffle Data and Labels

Generate a randomly permuted index list and use this index list to reorder the padded sequences and labels, thus shuffling the data order.


shuffle_indices = np.random.permutation(len(padded_sequences))
padded_sequences = padded_sequences[shuffle_indices]
labels = labels[shuffle_indices]

Step 10: Train the Discriminator

Train using nested loops; the outer loop iterates over epochs, while the inner loop iterates over batches.


batch_size = 32
num_epochs = 10
num_batches = len(padded_sequences) // batch_size

for epoch in range(num_epochs):
    for batch in range(num_batches):
        batch_data = padded_sequences[batch * batch_size : (batch + 1) * batch_size]
        batch_labels = labels[batch * batch_size : (batch + 1) * batch_size]

        discriminator_loss = discriminator.train_on_batch(batch_data, batch_labels)

        print(f"Epoch {epoch + 1}, Batch {batch + 1}/{num_batches}, Loss: {discriminator_loss[0]}, Accuracy: {discriminator_loss[1]}")

Step 11: Save Trained Discriminator Weights

Save the trained discriminator weights to a specified file for future use or loading.


discriminator.save_weights('discriminator_weights.weights.h5')

Step 12: Classify Sample Emails

After tokenizing and padding sample email texts, use the trained discriminator to classify emails and output prediction results.


sample_email_texts = [
    "Congratulations! You've won a million dollars!",
    "Hi there, I hope you're doing well.",
    "Get a discount on our new products today!"
]

sequences = tokenizer.texts_to_sequences(sample_email_texts)
padded_sequences = pad_sequences(sequences, maxlen=max_sequence_length)

predicted_labels = discriminator.predict(padded_sequences)

predicted_classes = ["Spam" if label > 0.5 else "Ham" for label in predicted_labels]

for i, email_text in enumerate(sample_email_texts):
    print(f"Email {i + 1}: {email_text}")
    print(f"Predicted Class: {predicted_classes[i]}")
    print(f"Predicted Score: {predicted_labels[i][0]:.4f}")
    print()
